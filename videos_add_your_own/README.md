# Custom Exercise Videos Directory

This folder is provided as a drop-in asset location for your custom exercise recordings, computer vision demo clips, and form-tracking MP4 files.

### How to use your own demo videos:
1. Record your exercise demonstration in MP4 format (H.264 video codec recommended for universal browser playback).
2. Place your video files in this folder or replace files in `../videos/`.
3. Update the corresponding `switchVideo('videos/<your-video>.mp4', this, '<EXERCISE-NAME>')` calls in `../index.html`.
