# Contributing to AI Gym Coach Landing Page

Thank you for considering contributing to the **AI Gym Coach Landing Page**! We welcome community contributions, bug reports, and design enhancements.

## Code of Conduct

This project adheres to our [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.

## Getting Started

1. **Fork the Repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/YOUR-USERNAME/ai-gym-coach-landing-page.git
   cd ai-gym-coach-landing-page
   ```
3. **Open the project**:
   - Simply double-click `index.html` or run a local server:
     ```bash
     # Using Python
     python -m http.server 3000

     # Using Node
     npx serve .
     ```
   - Visit `http://localhost:3000` in your browser.

## Making Changes

1. Create a descriptive feature branch:
   ```bash
   git checkout -b feature/my-new-feature
   ```
2. Make your edits to `index.html`, `style.css`, or add media assets.
3. Test across desktop and mobile screen widths (Chrome DevTools Device Toolbar).
4. Verify that all asset paths (`IMGs/`, `videos/`, `fonts/`) are case-sensitive and function without 404s.

## Submitting a Pull Request

1. Commit your changes with a clear message:
   ```bash
   git commit -m "feat(ui): add new interactive metrics counter"
   ```
2. Push to your branch:
   ```bash
   git push origin feature/my-new-feature
   ```
3. Open a Pull Request on GitHub against the `main` branch.
4. Fill out the pull request template with screenshots if applicable.
